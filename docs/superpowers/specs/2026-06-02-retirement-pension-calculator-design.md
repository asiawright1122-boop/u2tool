# Design Spec - 个人退休金与养老理财优化器 (Retirement & Pension Optimizer)

本规范定义了高交互旗舰金融工具 **“个人退休金与养老理财优化器”**（`retirement-pension-calculator`，组件：`RetirementPensionCalculator.svelte`）的技术方案与设计契约。

---

## 1. 背景与产品目标

随着全球性延迟退休政策的实施与通货膨胀对货币购买力的蚕食，大众对未来养老储蓄产生了两大核心痛点：
1. **“纸面富贵”幻觉**：传统的养老金计算器只计算几十年后复利翻滚出来的庞大名义数字，完全忽略了通胀贬值，导致用户对晚年资产的真实购买力产生严重误判。
2. **缺乏理财优化路径**：用户不知道如何通过提高年化投资回报率或微调每月缴存额来对冲通胀，跨越养老危机。

本工具旨在：
* **揭示通胀真相**：首创名义总资产与“挤干通胀水分”后的**真实购买力折现双曲线**。
* **智能安全度级**：提供四段式晚年自由度安全评级，诊断养老金缺口。
* **曜石黑金美学**：采用“金秋麦浪 (Golden Harvest)”黑金主题。

## 3. 核心精算数学公式

设输入参数为：
* 当前年龄 $A_{start}$，预期退休年龄 $A_{retire}$（联动约束：$A_{retire} \ge A_{start} + 1$），预期养老金领取年限 $Y_{payout}$（默认 30 年，滑动范围 `[10, 50]` 年）。
* 累计理财/缴存月份 $N = (A_{retire} - A_{start}) \times 12$（采用 Math.round 防御小数精度）。
* 初始养老金储备（已累积）为 $P_0$。
* 每月新增存入额（理财额）为 $M$（假定为名义恒定额，旨在揭示通胀对定期定额投资的蚕食效应）。
* 预期年化收益率为 $R_{annual}$（限制区间：`[-10%, 30%]`），折算为月复利收益率 $r = (1 + R_{annual})^{1/12} - 1$。
* 预估年化通货膨胀率为 $F_{annual}$（限制区间：`[0%, 20%]`，通缩最低设为 0%），折算为月通胀率 $f = (1 + F_{annual})^{1/12} - 1$。

对于第 $t$ 个月（$t = 1, 2, \dots, N$），采用如下鲁棒性精算方程：

### 3.1 名义总资产余额 $P_t$（未考虑通胀）
若理财月收益率 $r > 0$，采用高性能闭式公式：
$$P_t = P_0 (1+r)^t + M \frac{(1+r)^t - 1}{r}$$
若理财月收益率 $r = 0$（特判防 NaN 崩溃），采用退化线性方程：
$$P_t = P_0 + t \times M$$
若理财月收益率 $r < 0$ 且收益率非 0，也可正常采用复利闭式计算。

### 3.2 实际购买力折现值 $Real\_P_t$
将未来的名义金额按月通胀率折现回 $t=0$（相当于今天的货币价值）：
$$Real\_P_t = \frac{P_t}{(1 + f)^t}$$

### 3.3 退休后折现月度可支配（领款期 $Y_{payout}$ 年，即 $N_{payout} = Y_{payout} \times 12$ 个月）
在退休时，假定用户退休期理财收益与通胀相抵（实际收益率为 0），每月等效于今天的购买力金额为：
$$Monthly\_Real = \frac{Real\_P_N}{N_{payout}}$$

### 3.4 晚年自由度安全评级算法
设用户期望的退休后每月基本生活费为 $Exp\_Monthly$（默认以当前月度存入额的 1.5 倍为参考，或提供基数 ¥4,000 元）。
安全系数 $Safety\_Ratio = Monthly\_Real / Exp\_Monthly$：
* $Safety\_Ratio < 1.0$ $\rightarrow$ 🔴 **脆弱 (Fragile)**
* $1.0 \le Safety\_Ratio < 1.5$ $\rightarrow$ 🟡 **基本 (Basic)**
* $1.5 \le Safety\_Ratio < 2.5$ $\rightarrow$ 🟢 **富足 (Comfortable)**
* $Safety\_Ratio \ge 2.5$ $\rightarrow$ 👑 **财务自由 (Free)**

## 4. ECharts 曜石黑金配置契约

* **主题样式**：背景透明，文本使用香槟金 (`#E5C47F` / `#B38F3B`)。大额关键数字必须使用 Svelte 5 的 `spring` 或 `tweened` 动效库实现平滑的数值滚动过渡。
* **名义资产曲线**：
  * 类型：`line`，平滑曲线 (`smooth: true`)。
  * 填充颜色：线性渐变 `#BF953F` 到 `#FCF6BA` 的 `areaStyle`（金色麦浪面积图）。
  * 阴影：`shadowBlur: 10`, `shadowColor: 'rgba(212, 175, 55, 0.3)'`。
* **实际购买力曲线**：
  * 类型：`line`，虚线 (`type: 'dashed'` 配置在 `lineStyle` 中)。
  * 颜色：高对比香槟铜金 (`#C5A059`)，以确保在曜石黑背板下的 WCAG 2.1 无障碍对比度 > 3:1。
* **流光与拟物微交互**：
  * **流光 (Shimmer)**：Header 标题及关键按钮边框配置 CSS `@keyframes` 渐变位移动画（利用滚动 `background-position`，色值采用 `#FCF6BA` 到 `#BF953F` 的金属渐变）。
  * **指示灯 (Neon Capsule)**：四段式安全评级指示灯采用毛玻璃质感（`backdrop-filter: blur(8px)` + 内发光 `box-shadow`），激活态应用对应的 radial-shadow 发光滤镜（`filter: drop-shadow(0 0 8px currentColor)`）与呼吸灯动效。

## 5. 10 大语系备用字典契约

在组件中硬编码 `I18N_LABELS` 包含 10 大语系（ZH, EN, ES, PT, JA, RU, FR, AR, DE, KO）的所有专有词汇与评级警告。
**分语系黄金 SEO 描述字符约束**：为了解决中英文信息密度差异，避免单测校验失败：
*   **CJK 语系 (ZH, JA, KO)**：`seo_description` 长度必须限制在 **70 - 100 字符**。
*   **表音与西欧语系 (EN, DE, ES, PT, RU, FR, AR)**：`seo_description` 长度必须限制在 **120 - 160 字符**（含空格）。

* **ZH 示例**：
  * **name**: "个人退休金与养老理财优化器"
  * **description**: "结合通货膨胀模型算清您未来的实际退休金购买力，提供补充理财复利优化与自由度安全精算。"
  * **seo_description**: "免费在线个人退休金与养老理财优化器，输入年龄、已存养老金、每月存入及收益率，结合动态通胀模型反推折现购买力，金秋麦浪双曲线对比名义财富与实际购买力走势，助您跨越通胀大山实现晚年财务自由。"
