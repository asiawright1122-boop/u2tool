## 💡 修复技巧

### 1. 使用推荐策略

选择 **策略 1: 自动修复所有问题** 可以一次性解决大部分问题。

### 2. 查看修复报告

修复完成后会生成详细报告，包括：
- 成功修复的操作
- 失败的操作
- 需要人工审核的翻译

### 3. 分批处理

如果问题太多，可以：
1. 先修复高优先级问题（策略 2）
2. 再修复翻译键错误（策略 3）
3. 最后修复命名问题（策略 4）

### 4. 保留备份

所有修复操作都会自动备份，如果出现问题可以回滚：

```bash
# 查看备份
ls -la backups/

# 恢复备份
cp backups/fix-1234567890/zh.json.backup src/messages/zh.json
```
