## 添加新工具指南

### 必要步骤

添加新工具时，**必须**完成以下所有步骤：

#### 1. 工具配置 (`src/config/tools.ts`)

```typescript
{ slug: 'your-tool-slug', category: 'category', icon: '🔧', component: 'YourToolComponent', popular: false }
```

#### 2. 动态导入注册 (`src/components/tools/ToolWrapper.tsx`)

```typescript
'your-tool-slug': dynamic(() => import('./YourToolComponent'))
```

#### 3. 组件文件 (`src/components/tools/YourToolComponent.tsx`)

创建工具组件文件，使用 `export default` 导出。

#### 4. 翻译文件 (`src/messages/*.json`)

在所有 10 个语言文件中添加翻译：

```json
{
  "tools": {
    "your-tool-slug": {
      "name": "工具名称",
      "description": "工具描述",
      "seo_title": "SEO 标题",
      "seo_description": "SEO 描述"
    }
  }
}
```

- `en.json` (英文)
- `zh.json` (中文)
- `ja.json` (日文)
