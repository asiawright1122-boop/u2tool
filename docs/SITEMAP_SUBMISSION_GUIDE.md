## 1. Google Search Console

### 提交步骤

1. **访问平台**
   - 网址：https://search.google.com/search-console
   - 使用 Google 账号登录

2. **选择站点**
   - 选择 `https://www.u2tool.com`

3. **提交 Sitemap**
   - 左侧菜单 → **Sitemap**
   - 在 "添加新的 sitemap" 输入框输入：`sitemap.xml`
   - 点击 **提交**

4. **验证**
   - 提交后状态会显示为 "成功" 或 "发现错误"
   - 通常 1-3 天内开始抓取

### 直接链接
- Sitemap 页面：https://search.google.com/search-console/sitemaps?resource_id=sc-domain%3Awww.u2tool.com

## 🔍 验证 Sitemap

### 检查 Sitemap 是否可访问

```bash
# 检查 sitemap 是否可访问
curl -I https://www.u2tool.com/sitemap.xml

# 查看 sitemap 内容（前 50 行）
curl -sL https://www.u2tool.com/sitemap.xml | head -50

# 统计 URL 数量
curl -sL https://www.u2tool.com/sitemap.xml | grep -c "<url>"
```

## 📝 注意事项

1. **提交后等待**
   - 提交后通常需要 1-7 天才能看到效果
   - Google 和 Bing 通常较快（1-3 天）
   - 百度可能需要更长时间（3-7 天）

2. **定期检查**
   - 建议每周检查一次提交状态
   - 查看是否有错误或警告

3. **更新 Sitemap**
   - Sitemap 会在每次部署时自动更新
   - 无需手动重新提交（除非有错误）

4. **IndexNow 补充**
   - 除了 Sitemap，还可以使用 IndexNow 实时通知更新
   - 运行：`npx ts-node scripts/submit-indexnow.ts`
