# Requirements: v0.0.20 - Edge Redirect KV Automation & Release Pipeline

## Milestone Goal

建立自动化往 Cloudflare KV 写入最新重定向映射的同步与发布机制，打通从 404 URL 生成配对到边缘层上线的 E2E 自动化链条。

## Requirements

### Dynamic Recovery Pipeline (GEO)

- [ ] **GEO-06** - **E2E Cloudflare KV Write Integration**: 建立自动化往 Cloudflare KV 写入最新映射的同步与发布管线。
  - 实现本地 CLI 控制台脚本（如 `scripts/gsc-recovery/publish-mappings.ts`），支持将 `src/config/gsc-redirects.json` 中的数据自动写入 Cloudflare KV namespace。
  - 通过环境变量或本地安全凭证（`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `KV_NAMESPACE_ID`）安全接入 Cloudflare REST API，或者以 Wrangler 子进程命令形式进行同步。
  - 具备防雪崩与发布保护机制：如果 json 文件为空或格式损坏，命令必须报错拦截并终止发布；支持在写入前比对 KV 中已存在的 Key，确保发布过程是幂等或增量的，严防由于发布异常抹除线上的非冲突重定向配置。
- [ ] **GEO-07** - **KV Pipeline Integration Validation**: 针对线上/沙盒环境下的实际 KV 匹配链路进行 E2E 重定向与防环路闭环回归测试。
  - 扩展本地测试验证脚本（如引入或调整 `scripts/validation/` 相关流程），支持在沙盒模拟 KV 读取的真实重定向链路。
  - E2E 验证链路必须覆盖重定向透传原始 Query 参数、匹配 Locale 前缀的准确性，且必须包含动态重定向闭环检测逻辑，确保新增的重定向配置不会与系统已有路由产生循环跳转（环路）。

## Future Requirements (Deferred)

- **GEO-08** - **Real-time Live Domain Redirection Crawler Check**: 自动化监控生产域名（`https://www.u2tool.com`）上所有已激活重定向规则的连通性（延后至 v0.0.21+ 解决）。

## Out of Scope

- 开发可视化的重定向规则后台管理界面。
- 同步或更新 Cloudflare 边缘端除重定向 KV 外的其他配置（如 Pages 变量或路由文件）。
