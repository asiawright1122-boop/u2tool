This is another **bounded metadata cleanup** milestone. It does not redesign validators, change thresholds, or mass-edit multilingual copy. The expected outcome is a measured 10-warning reduction while preserving `0` hard errors and synchronized root/base metadata.

## Motivation

- **The cleanup loop remains repeatable**: the previous eight batches each removed 10 warning-only findings without validator changes.
- **RU candidates remain near the top**: multiple high-overrun Russian candidates still require language-review-sensitive handling, so this batch stays in the lower-risk Latin-script lane and records the skip explicitly.
- **Warning debt should keep moving downward**: this batch keeps the candidate queue actionable while preserving hard-error semantics.
- **Evidence-led selection remains important**: same-overrun candidates can display differently in CLI summaries, so this milestone follows the fresh candidate JSON and records locale-safety skips.

1. **Edit both layers together**: every selected root/base pair must end with identical values.

4. **Measure before and after**: record the exact warning-count delta.
5. **Leave reports ignored**: `.planning/research/reports/` remains untracked.
