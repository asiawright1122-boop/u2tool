# Requirements: v0.0.21 - Live Redirection Connection Monitoring & Crawler

## Milestone Goal

建立生产域名上已激活重定向规则的实域连通性与 HTTP 跳转深度扫描爬虫检测系统，确保流量无缝流转，防范死循环与软 404，并对跳转目标 HTML 做安全审计。

## Requirements

### Dynamic Recovery Pipeline (GEO)

- [x] **GEO-08-01** - **Redirection Matrix Expansion & Fetch Pool**: 将 `gsc-redirects.json` 配置项扩展为 10 语种前缀测试矩阵，并以受控并发池 + WAF 放行头实域探测连通性。
  - 新建连通性检测脚本 `scripts/validation/validate-live-redirects.ts`，将每条规则扩展出 11 个测试配置（1 默认 + 10 语种前缀）。
  - 实现限制最大并发 ≤5 的队列池，并注入 50–150ms 随机抖动（Jitter）。
  - 支持 `redirect: 'manual'` 抓取跳转 Location，桌面 Chrome UA + 可选 `x-waf-bypass-token` 头实现 Cloudflare WAF 放行；指数退避 `500*attempt` + AbortController 超时重试。
- [x] **GEO-08-02** - **Redirection Hop Tracer**: 追踪多跳重定向链路（A→B→C）直至终点，记录完整 hop 链。
  - `traceRedirectChain` 通过 non-recursive while 模式沿 Location 头跟进，最多 `MAX_REDIRECTS=5` 跳。
  - 每条链路返回 `chain: HopInfo[]`，含每个节点的 URL/状态/Location。
- [x] **GEO-08-03** - **Loop Blocker & Param Normalization**: 防御死循环重定向，并消除查询参数顺序漂移导致的假阳性/假阴性。
  - per-chain `visited` Set 在重复请求前阻断环路（A→B→A），错误信息含环路路径。
  - `normalizeUrlForComparison` 对查询参数排序归一；保留尾斜杠以区分正常规范化跳转与真环路。
  - `suggestFlatten` 对深度 ≥2 的链路给出压平建议（纯报告，绝不改写 `gsc-redirects.json`）。
- [x] **GEO-08-04** - **HTML Safety Auditor**: 对跳转终点 HTML 做软 404 / 推理痕迹泄露 / noindex 审计。
  - `auditHtmlSafety(html, locale)` 纯函数扫描器，永不因畸形 HTML 崩溃。
  - 软 404 关键词覆盖 10 语种，仅扫 `<h1>`/`<title>` 避免正文误报。
  - 推理痕迹检测复用 `src/lib/safety-patterns.ts` 单一真源（ADR 0002 契约）。
- [x] **GEO-08-05** - **Production Gate**: 将 HTML 审计纳入可选的 `--online` 发布检测门禁。
  - `--online` / `LIVE_REDIRECT_ONLINE=1` 门禁：仅显式开启时抓取终点 HTML，避免 `qa:production` 误打生产域名。
  - 脱敏 JSON 报告写入 gitignored 的 `.planning/research/reports/`，仅含公开字段。
  - `package.json` 暴露 `validate:live-redirects:online`，base 命令保持离线。
