## Active Milestone: v0.0.19 - GSC Recovery Automation & Long-tail Expansion

本里程碑致力于实现 GSC Excluded 404 URL 恢复重定向的动态化与半自动化生成机制，并进一步优化和对齐长尾语系的旗舰工具 SEO/GEO 元数据。

- [x] **Phase 69: Dynamic GSC Recovery Redirect Engine** (Requirements: `GEO-04`)
- [x] **Phase 70: Automatic Redirect Generator & Exclude Intake Pipeline** (Requirements: `GEO-05`)
- [x] **Phase 71: Long-Tail Locale & Flagship SEO Alignment** (Requirements: `LTDK-04`)

### Phase 69: Dynamic GSC Recovery Redirect Engine
**Goal:** 设计并开发运行时动态重定向机制。支持从静态打包的 JSON 文件或基于边缘 Workers KV 的在线配置中动态读取重定向表，实现免发布快速上线重定向。

- **Success Criteria**:
  - 改造 `src/lib/gsc-recovery-redirects.ts` 和 `src/middleware.ts` 接入动态获取逻辑与内存缓存，保证 Worker CPU 时间未出现限制。
  - 单元测试覆盖动态匹配、KV 异常降级和防重定向环路保护。

### Phase 70: Automatic Redirect Generator & Exclude Intake Pipeline
**Goal:** 开发 Node 控制台脚本，自动拉取/接收 GSC 导出的 Excluded 404 页面，并自动检索系统路由，通过 URL 路径模糊匹配或文本相似度自动推荐重定向映射并生成 JSON。

- **Success Criteria**:
  - 编写 `scripts/gsc-recovery/generate-mappings.ts` 能够接收 404 URL 列表文件并输出高保真重定向映射结果。
  - 提供 CLI 级别的仿真运行验证。

### Phase 71: Long-Tail Locale & Flagship SEO Alignment
**Goal:** 对 `macro-calculator`、`one-rep-max-calculator`、`calorie-deficit-calculator` 等长尾高意图旗舰工具，精细调优 10 种语言下的元数据，补全 localized support copy。

- **Success Criteria**:
  - 补全所有 long-tail locales 的翻译和描述性文案，确保符合 length 界限且绝无英文残留。
  - `npm run verify:production` 依然全绿通过。
