## 4. Integration & E2E Flow Validation

Cross-phase integration has been validated through automated E2E tests simulating real browser actions using Puppeteer.
- **Trailing Slash 301 & Query Preservation**: Navigation from `/en/tools/json-formatter?utm_source=twitter` to `/en/tools/json-formatter/?utm_source=twitter` was tracked in the Puppeteer redirect chain. Query parameters were successfully preserved.
- **Legacy Blog Redirection**: Navigation to `/zh/blog/non-existent-blog` redirected cleanly to the parent category root `/zh/tools/`.
- **410 Gone Headers**: Intercepted HTTP responses for stale assets (`/_next/static/chunks/main.js`) and decommissioned comparisons (`/en/tools/compare/choose-json-tool/`) returned HTTP 410, carrying `x-robots-tag: noindex, nofollow` and `cache-control: public, max-age=86400, s-maxage=86400`.

## 5. Technical Debt & Deferred Gaps

- **Astro Preview Server Redirection Bypass**: In local preview servers (Astro Preview), requests to dynamic routes without trailing slashes (e.g. `/tools/categories/text`) are permanently redirected by Astro before reaching edge middleware. Tests and verification scripts adapt to this by directly testing canonical trailing-slash URLs (e.g., `/tools/categories/text/`). This is a known local environment limitation and does not affect the production Cloudflare Pages Worker behavior.
