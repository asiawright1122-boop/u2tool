## Key Outcomes Confirmed

- **Loop-Safe Multi-Hop Tracing**: Per-chain visited Set catches redirect cycles before the repeated request, with query-param normalization preventing both false loops (param order drift) and false passes (trailing-slash masking).
- **ADR 0002 Enforced on Live HTML**: The reasoning-trace contract is now asserted against production HTML, not just source files, via a single shared pattern source shared by both scanners.
- **Opt-In Production Gate**: `validate:live-redirects:online` enables body auditing + JSON reporting only on demand; the base command stays offline-safe for local CI.

## Residual Risks / Tech Debt

- **Soft-404 keyword dictionary is hand-curated**: The 10-locale dictionary may miss locale-specific error phrasings; it errs toward precision (heading-only scan) to avoid false positives, at the cost of some recall.
- **`validate:live-redirects:online` not yet wired into `qa:production`**: The online probe is available as an opt-in script but is deliberately not part of the default release gate, since it hits the live domain. Wiring it into a post-deploy step is a future operational decision.
- **TDK drift verification deferred**: Per FEATURES.md this is a v2+ / HIGH-complexity item; the soft-404 scan is the lighter proxy for this milestone.

## Verdict

The milestone v0.0.21 is fully ready for archival. All three phases are implemented, 38 probe unit tests and the front-end-safety scan are green, and the ADR 0002 contract is enforced on live HTML via a single-source pattern set.
