# Requirements: v0.0.19 - GSC Recovery Automation & Long-tail Expansion

## Milestone Goal

实现 GSC Excluded 404 URL 恢复重定向的动态化与半自动化生成机制，并进一步优化和对齐长尾语系的旗舰工具 SEO/GEO 元数据。

## Requirements

### Dynamic Recovery Infrastructure (GEO)

- [ ] **GEO-04** - **Dynamic GSC Recovery Redirect Engine**: 在边缘层中间件中实现动态化路由匹配与重定向能力。
  - 支持从动态打包的静态资源（如 `gsc-redirects.json`）中读取映射，并且设计可接入 Cloudflare KV 的异步读取机制。
  - 必须包含 Workers 级别的性能保护：在内存中对 KV 查询结果进行高性能本地缓存（如使用局部变量或 Map），避免每个请求产生同步网络开销；对于不存在的映射做好防击穿，确保在高 QPS 访问下 CPU 时间安全。
  - 保留并透传查询参数、进行 locale 语系匹配以及防止重定向闭环。
- [ ] **GEO-05** - **Automatic Redirect Generator & Pipeline**: 开发 Node.js CLI 控制面脚本。
  - 该脚本能接收来自 GSC 的 404/Excluded 报错 URL 列表。
  - 利用系统已注册的路由表进行比对（模糊路径匹配或文字相似度计算），自动推荐并生成对应的重定向映射表（JSON 格式）。

### Translation & Metadata Quality (LTDK)

- [ ] **LTDK-04** - **Long-Tail Locale Content & Metadata Alignment**: 对 `macro-calculator`、`one-rep-max-calculator`、`calorie-deficit-calculator` 等旗舰级长尾重点工具进行 10 种语言下的 TDK 元数据和 localised support copy 精细化审核。
  - 严格校验并修复长度溢出（Title <= 35 字符，Description <= 180 字符）以及翻译逻辑生硬、漏译或 placeholder 英文残留问题。
  - 确保这些工具页面整体内容质量符合 Google / GEO 对核心实体的高标准。

## Future Requirements (Deferred)

- **GEO-06** - **E2E Cloudflare KV Write Integration**: 建立自动化往 Cloudflare KV 写入最新映射的同步机制（延后至 v0.0.20+ 解决）。

## Out of Scope

- 对 Cohort C 队列之外的非高曝光低优先级工具页面进行精细人工文案修复。
- 自动化更新除 GSC 重定向和指定长尾工具外的其他系统配置。
