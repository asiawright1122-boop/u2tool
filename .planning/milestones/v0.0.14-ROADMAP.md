# Roadmap: v0.0.14 Production Release and GSC Recovery Measurement

**Milestone:** v0.0.14 Production Release and GSC Recovery Measurement
**Status:** Active
**Started:** 2026-06-09

## Goal

Recover organic traffic by safely deploying the completed recovery work, verifying the live site contract, and measuring repaired page cohorts in Google Search Console instead of continuing local-only improvements.

## Phase Numbering

Phase numbering continues from v0.0.13 (last phase: 52).

**Requirements:** R1, R2

**Goal:** Convert repaired URLs into a bounded Search Console recovery queue with request-indexing and monitoring rules.
**Requirements:** R5

- [x] 55-03: Record the exact URL list and owners for follow-up.

### Phase 56: Recovery Measurement and Closeout

**Goal:** Measure whether the deployed recovery work produces improved impressions, clicks, CTR, and crawl/index status.
**Requirements:** R6

- [x] 56-01: Create the 7-day / 14-day / 28-day GSC measurement report structure.
- [x] 56-02: Compare cohort movement against pre-release baseline exports.
- [x] 56-03: Close the milestone with production route, frontend safety, GSC measurement, and next-wave recommendations.

## Exit Criteria

- Release manifest exists and does not include unrelated dirty-worktree changes.
- Production route contract remains green.
- Latest v0.0.13 support-content closeout slice is visible on live pages.
- GSC recovery cohort plan exists with monitoring dates and URL ownership.
- Measurement report records whether traffic is recovering, flat, or still declining by cohort.
