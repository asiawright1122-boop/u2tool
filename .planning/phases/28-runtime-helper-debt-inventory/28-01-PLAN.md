# 28-01 Plan

## Goal

Build a deterministic runtime helper debt inventory report from actual `tool-stubs.ts` imports and export signatures.

## Must Be True

1. The report is generated from code, not manually curated.
2. Imported `tool-stubs.ts` exports are mapped to consumer component paths and export source locations.
3. Placeholder signatures and false-positive notes are visible enough for later phases to choose repair scope safely.

## Initial Tasks

- Add a TypeScript report script that parses:
  - `src/lib/tool-stubs.ts`
  - `src/components/**/*.svelte`
  - `src/lib/**/*.ts` where relevant
- Detect imported export names, export kind, source line, consumer count, and likely placeholder signatures.
- Add a package script for deterministic regeneration.
- Generate `docs/RUNTIME_HELPER_DEBT_INVENTORY.md`.

## Verification

```bash
npm run report:runtime-debt
git diff --check
```

## Success Criteria

- Inventory report exists and lists summary counts plus ranked candidate tables.
- False positives are explicitly separated from likely broken helper candidates.
- The script can be rerun without manual edits.
