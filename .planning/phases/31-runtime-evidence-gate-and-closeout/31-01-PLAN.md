# 31-01 Plan

## Goal

Extend runtime placeholder governance so the Phase 29 and Phase 30 reference-data repairs cannot silently regress to empty compatibility exports.

## Must Be True

1. `scripts/validation/validate-runtime-placeholder-regressions.ts` protects const exports as well as function exports.
2. All selected Phase 29 and Phase 30 helpers are in the protected helper list.
3. The governance script passes and still runs through `validate:runtime-placeholder-regressions`.

## Initial Tasks

- Read `scripts/validation/validate-runtime-placeholder-regressions.ts`, `src/lib/tool-stubs.ts`, `src/lib/tool-stubs-runtime.test.ts`, `src/lib/runtime-integrity/text-reference.ts`, and `src/lib/runtime-integrity/validation-reference.ts`.
- Add a helper `kind` or equivalent metadata field for protected entries.
- Keep existing function wrapper checks for current function helpers.
- Add const-delegation checks that verify:
  - `tool-stubs.ts` imports the export as the configured runtime alias from the configured module path.

  - `src/lib/tool-stubs-runtime.test.ts` references `EXPORT_NAME`.
- Add protected entries for `ASCII_FONTS`, `MORSE_CODE`, `REVERSE_MORSE`, `NATO_ALPHABET`, `smallCapsMap`, `subscriptMap`, `superscriptMap`, `flipMap`, `mirrorMap`, `commonPasswords`, `commonTypos`, `disposableDomains`, and `freeProviders`.
