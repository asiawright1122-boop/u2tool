# U2Tool - 免费在线开发者工具箱

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fwww.u2tool.com)](https://www.u2tool.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Next.js](https://img.shields.io/badge/Next.js-14-black)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue)](https://www.typescriptlang.org/)

一个 SEO 友好、支持多语言的免费在线工具站，提供 200+ 开发者常用工具。基于 Next.js 14 构建，完全免费，无需注册。

🌐 **在线访问**: [https://www.u2tool.com](https://www.u2tool.com)

## ✨ 特性

- 🌍 **多语言支持**: 英语、中文、西班牙语、葡萄牙语、日语
- 🔍 **SEO 优化**: 自动生成 sitemap、多语言 hreflang 标签、结构化数据
- ⚡ **高性能**: 静态生成、边缘部署、Core Web Vitals 优化
- 🎨 **现代 UI**: Tailwind CSS、暗色主题、响应式设计
- 🔒 **隐私安全**: 所有处理在浏览器本地完成，数据不上传服务器
- 📱 **移动友好**: 完美适配各种设备尺寸
- 💰 **完全免费**: 无需注册，无使用限制

## 🚀 快速开始

### 在线使用

直接访问 [https://www.u2tool.com](https://www.u2tool.com) 即可使用所有工具，无需安装。

### 本地开发

```bash
# 克隆仓库
git clone https://github.com/your-username/u2tool.git
cd u2tool

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务
npm start
```

## 📦 部署

### 部署到 Vercel（推荐）

1. Fork 这个仓库
2. 在 [Vercel](https://vercel.com) 中导入项目
3. 设置环境变量
4. 点击部署

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/u2tool)

### 环境变量

```env
NEXT_PUBLIC_BASE_URL=https://your-domain.com
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
INDEXNOW_KEY=your-indexnow-key
```

## 🏗️ 技术栈

- **框架**: [Next.js 14](https://nextjs.org/) (App Router)
- **语言**: [TypeScript](https://www.typescriptlang.org/)
- **样式**: [Tailwind CSS](https://tailwindcss.com/)
- **国际化**: [next-intl](https://next-intl-docs.vercel.app/)
- **测试**: [Vitest](https://vitest.dev/) + [Playwright](https://playwright.dev/)
- **部署**: [Vercel](https://vercel.com/)

## 📁 项目结构

```
src/
├── app/                    # Next.js App Router 页面
│   ├── [locale]/          # 多语言路由
│   │   ├── tools/         # 工具页面
│   │   └── page.tsx       # 首页
│   └── api/               # API 路由
├── components/            # React 组件
│   ├── tools/            # 工具组件
│   ├── layout/           # 布局组件
│   └── ui/               # UI 组件
├── config/               # 配置文件
│   └── tools.ts          # 工具配置
├── lib/                  # 工具函数
├── messages/             # 多语言文案
└── styles/               # 样式文件
```

### 添加新工具

1. 在 `src/config/tools.ts` 添加工具配置
2. 在 `src/messages/*.json` 添加多语言文案
3. 在 `src/components/tools/` 创建工具组件
4. 在 `src/components/tools/ToolWrapper.tsx` 注册组件
5. 提交 Pull Request
