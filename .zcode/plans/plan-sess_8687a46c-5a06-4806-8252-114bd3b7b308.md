# 移除世界杯相关工具实施方案

## 背景与目标
用户明确要求：“移除世界杯相关工具，已经过去了”。
当前代码库共有 6 款与世界杯相关的工具：
1. `world-cup-simulator` (世界杯模拟器)
2. `world-cup-budget-calculator` (世界杯预算计算器)
3. `world-cup-timezone-planner` (世界杯时区规划器)
4. `world-cup-visa-assistant` (世界杯签证助手)
5. `world-cup-group-calculator` (世界杯分组计算器)
6. `world-cup-2026-bracket-predictor` (2026世界杯分组预测器)

本方案将完整下线这 6 款工具及其专属支撑逻辑、组件与多语言配置，并对已收录的 URL 做好 410 Gone / 优雅下线治理。

---

## 实施步骤

### 1. 工具元数据注销 (`src/config/tools/fun.ts` 与 `ToolImportMap.ts`)
- 从 `src/config/tools/fun.ts` 中移除全部 6 款工具的定义。
- 从 `src/components/tools/ToolImportMap.ts` 中移除 6 款工具的动态组件映射。
- 工具总数由 570 调整为 564。

### 2. 移除相关 UI 组件与专属页面
- 删除 Svelte 组件：
  - `src/components/tools/WorldCupSimulator.svelte`
  - `src/components/tools/WorldCupBudgetCalculator.svelte`
  - `src/components/tools/WorldCupTimezonePlanner.svelte`
  - `src/components/tools/WorldCupVisaAssistant.svelte`
  - `src/components/tools/WorldCupGroupCalculator.svelte`
  - `src/components/tools/WorldCup2026BracketPredictor.svelte`
  - `src/components/tools/world-cup-group-calc/` 目录（3个子组件）
  - `src/components/tools/WorldCupSimulator.test.ts`
- 删除专属日历 API 端点：
  - `src/pages/api/world-cup-calendar.ics.ts`
  - `src/pages/api/world-cup-calendar.ics.test.ts`

### 3. 移除专属核心计算库与数据集 (`src/lib/`)
- 删除世界杯专属算法与状态库：
  - `src/lib/world-cup-2026-bracket.ts` 及 `.test.ts`
  - `src/lib/runtime-integrity/world-cup-engine.ts` 及 `.test.ts`
  - `src/lib/runtime-integrity/world-cup-calc-state.svelte.ts` 及 `.test.ts`
  - `src/lib/runtime-integrity/world-cup-budget-calculator.ts` 及 `.test.ts`
  - `src/lib/runtime-integrity/world-cup-calculator-engine.ts` 及 `.test.ts`
  - `src/lib/runtime-integrity/world-cup-simulator-challenger.test.ts`
  - `src/lib/runtime-integrity/world-cup-visa-engine.ts` 及 `.test.ts`
  - `src/lib/data/world-cup-schedule.json`
  - `src/lib/data/world-cup-3rd-combinations.json`
- 清理引用：
  - `src/lib/tool-launches.ts`（移除 `world-cup-2026-bracket-predictor`）
  - `src/lib/ai-discovery/generated-aliases.ts`（移除对应别名条目）
  - `src/lib/translations.test.ts`（替换测试用例中引用的假数据 slug）

### 4. 清理多语言消息文件 (`src/messages/`)
- 删除 10 个语种下的 60 个独立工具 JSON 消息文件（如 `src/messages/*/tools/world-cup-*.json`）。
- 清理 `src/messages/*/base.json` 中的遗留词条键 `world-cup-2026-bracket-predictor`。
- 更新测试文件 `src/messages/high-opportunity-tools-i18n-seo.test.ts`。

### 5. SEO 与收录治理 (410 Gone / 抑制列表清理)
- 从 `src/config/index-suppression.generated.ts` 中彻底清除所有 `*/world-cup-*` 记录。
- 在中间件 `src/middleware.ts` 或 `src/lib/legacy-redirects.ts` 中增加下线路由拦截，向搜索引擎明确返回 `410 Gone`（通知 Google / Bingbot 彻底移除该工具索引，避免 404 爬取浪费）。
- 从 sitemap 生成中完全剔除上述路由。

### 6. 验证与回归测试
- 运行 `npm run check` 确保全站无类型引用缺失。
- 运行 `npm run qa:seo-governance`、`npm run qa:runtime-integrity` 与全站单元测试。
- 验证 sitemap 与路由完整性，确保构建成功。
