# Design Document: Semrush SEO Issues Fix

## Overview

本设计文档描述了修复 Semrush 网站检测报告中发现的 SEO 问题的技术方案。主要包括：

1. 为排名页面添加唯一的、本地化的 meta description
2. 优化所有页面的 title 长度（不超过 60 字符）
3. 优化 robots.txt 使用通配符模式处理 Next.js 动态资源
4. 添加排名页面 SEO 翻译键

## Architecture

### 组件关系图

### 数据流

1. 排名页面从翻译文件读取 `ranking_seo` 命名空间的 SEO 数据
2. SEO 库提供 title 截断和验证功能
3. robots.ts 生成优化的 robots.txt 配置
4. 验证脚本检查所有页面的 SEO 元数据

  return {
    title: seoTitle,

## Correctness Properties

*A property is a characteristic or behavior that should hold true across all valid executions of a system—essentially, a formal statement about what the system should do. Properties serve as the bridge between human-readable specifications and machine-verifiable correctness guarantees.*

### Property 1: Ranking Page Meta Description Uniqueness

*For any* ranking page type (newest or popular) and any locale, the meta description SHALL be unique and different from the generic site description.

**Validates: Requirements 1.1, 1.2, 1.5**

### Property 2: Meta Description Length Constraint

*For any* ranking page meta description in any locale, the length SHALL be between 120 and 160 characters.

**Validates: Requirements 1.4**

### Property 3: Title Tag Length Constraint

*For any* page title generated by the system, the length SHALL be no more than 60 characters.

**Validates: Requirements 2.1, 2.2**

### Property 4: Title Tag Contains Tool Name

*For any* tool page, the generated title SHALL contain the tool name.

**Validates: Requirements 2.3, 2.4**

### Property 5: Ranking SEO Translations Completeness

*For any* locale in the supported languages, the translation file SHALL contain complete ranking_seo keys for both "newest" and "popular" types with non-empty seo_title and seo_description.

**Validates: Requirements 4.1, 4.3, 4.4**

### Property 6: Robots.txt No Specific Chunk URLs

*For any* robots.txt output, it SHALL NOT contain specific hash-based chunk file URLs (e.g., `/chunks/abc123.js`).

**Validates: Requirements 3.2**

### Property 7: Llms.txt File Validity

*For any* llms.txt file, it SHALL follow the standard format and contain required sections (name, description, allowed/disallowed content).

**Validates: Requirements 6.2, 6.3, 6.4**

## Error Handling

### 翻译键缺失

如果 ranking_seo 翻译键缺失，系统应：
1. 回退到通用的 nav.newest/nav.hottest 翻译
2. 使用模板生成 description
3. 在开发环境记录警告

### Title 超长处理

如果生成的 title 超过 60 字符：
1. 使用 `truncateText` 函数截断
2. 优先保留工具名称
3. 可以省略站点名称

### 单元测试

- 测试 ranking_seo 翻译键在所有语言中存在
- 测试 title 截断逻辑
- 测试 robots.txt 输出格式

- 检查 ranking_seo 翻译完整性
