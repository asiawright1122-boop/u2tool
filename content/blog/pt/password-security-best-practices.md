# Melhores Práticas de Segurança de Senhas: Guia Completo 2025

A segurança de senhas continua sendo um dos aspectos mais críticos da cibersegurança. Este guia completo cobre como criar senhas fortes, ataques comuns e melhores práticas para usuários e desenvolvedores.

## Por Que a Segurança de Senhas Importa

De acordo com relatórios recentes de cibersegurança:

- **81%** das violações de dados envolvem senhas fracas ou roubadas
- **65%** das pessoas reutilizam senhas em múltiplas contas
- **23 milhões** de contas ainda usam "123456" como senha
- Custo médio de uma violação de dados: **$4,45 milhões**

## O Que Torna uma Senha Forte?

### Fatores de Força

| Fator | Fraca | Forte |
|-------|-------|-------|
| Comprimento | 6-8 caracteres | 12+ caracteres |
| Tipos de caracteres | Apenas letras | Misto (maiúsculas, minúsculas, números, símbolos) |
| Previsibilidade | Palavras do dicionário | Combinações aleatórias |
| Unicidade | Reutilizada | Única por conta |

### Tempo para Quebrar (estimativas 2025)

| Tipo de Senha | Exemplo | Tempo |
|---------------|---------|-------|
| 6 minúsculas | `abcdef` | Instantâneo |
| 8 minúsculas | `password` | 5 segundos |
| 8 mistas | `PassWord` | 22 minutos |
| 12 mistas + símbolos | `P@ss1234!abc` | 34.000 anos |

## Ataques Comuns de Senhas

### 1. Ataque de Força Bruta

Tenta todas as combinações possíveis.

**Defesa**: Senhas longas com caracteres mistos

### 2. Ataque de Dicionário

Usa palavras e senhas comuns.

**Defesa**: Evitar palavras do dicionário

## Melhores Práticas para Usuários

### Fazer ✅

1. Usar **senhas únicas** para cada conta
2. Usar um **gerenciador de senhas**
3. Habilitar **2FA/MFA** onde possível
4. Usar mínimo **12+ caracteres**
5. Incluir **todos os tipos de caracteres**

### Não Fazer ❌

1. **Não reutilizar** senhas entre contas
2. **Não usar informações pessoais** (aniversários, nomes)
3. **Não usar padrões comuns** (Password1!, Qwerty123)
