# Guia de Conversão de Formatos de Cor: HEX, RGB, HSL e Mais

Entender os formatos de cor é essencial para desenvolvedores web e designers. Este guia completo explica diferentes modelos de cor, quando usar cada um e como converter entre eles.

## Visão Geral dos Modelos de Cor

### RGB (Vermelho, Verde, Azul)

O modelo de cor digital mais comum, baseado em mistura aditiva:

```
Formato: rgb(red, green, blue)
Intervalo: 0-255 para cada canal
Exemplo: rgb(255, 99, 71) - Vermelho tomate
```

### HEX (Hexadecimal)

Representação compacta de RGB:

```
Formato: #RRGGBB ou #RGB (abreviado)
Intervalo: 00-FF (0-255 em hex)
Exemplo: #FF6347 - Vermelho tomate
```

### HSL (Matiz, Saturação, Luminosidade)

Mais intuitivo para humanos:

```
Formato: hsl(hue, saturation%, lightness%)
Matiz: 0-360 (graus na roda de cores)
Saturação: 0-100% (cinza a vívido)
Luminosidade: 0-100% (preto a branco)
```

## Quando Usar Cada Formato

| Formato | Melhor Para | Prós | Contras |
|---------|-------------|------|---------|
| HEX | CSS, design web | Compacto, amplo suporte | Difícil de ler/modificar |
| RGB | Manipulação programática | Operações matemáticas fáceis | Não intuitivo |
| HSL | Criar esquemas de cor | Ajustes intuitivos | Menos comum |
