# カラーフォーマット変換ガイド：HEX、RGB、HSL など

カラーフォーマットの理解は、Web開発者やデザイナーにとって不可欠です。この包括的なガイドでは、さまざまなカラーモデル、それぞれの使用場面、変換方法を解説します。

## カラーモデルの概要

### RGB（赤、緑、青）

最も一般的なデジタルカラーモデル、加法混色に基づく：

```
形式: rgb(red, green, blue)
範囲: 各チャンネル 0-255
例: rgb(255, 99, 71) - トマトレッド
```

### HEX（16進数）

RGBのコンパクトな表現：

```
形式: #RRGGBB または #RGB（省略形）
範囲: 00-FF（16進数で0-255）
例: #FF6347 - トマトレッド
```

### HSL（色相、彩度、明度）

人間にとってより直感的：

```
形式: hsl(hue, saturation%, lightness%)
色相: 0-360（カラーホイールの角度）
彩度: 0-100%（グレーから鮮やか）
明度: 0-100%（黒から白）
例: hsl(9, 100%, 64%) - トマトレッド
```

## 各フォーマットの使用場面

| フォーマット | 最適な用途 | 長所 | 短所 |
|--------------|------------|------|------|
| HEX | CSS、Webデザイン | コンパクト、広くサポート | 読みにくい |
| RGB | プログラム的な色操作 | 計算が簡単 | 直感的でない |
| HSL | カラースキーム作成 | 直感的な調整 | あまり一般的でない |


## カラー変換の公式

### RGB から HEX

```javascript
function rgbToHex(r, g, b) {
  return '#' + [r, g, b]
    .map(x => x.toString(16).padStart(2, '0'))
    .join('');
}

rgbToHex(255, 99, 71); // "#ff6347"
```

### HEX から RGB

```javascript
function hexToRgb(hex) {
  const result = /^#?([a-f\d]{2})([a-f\d]{2})([a-f\d]{2})$/i.exec(hex);
  return result ? {
    r: parseInt(result[1], 16),
    g: parseInt(result[2], 16),
    b: parseInt(result[3], 16)
  } : null;
}

hexToRgb("#ff6347"); // { r: 255, g: 99, b: 71 }
```

## HSLでカラースキームを作成

HSLを使用すると、調和のとれたカラースキームを簡単に作成できます：

### 補色

カラーホイールの反対側（180度離れている）：

```css
:root {
  --primary: hsl(200, 70%, 50%);      /* 青 */
  --complement: hsl(20, 70%, 50%);    /* オレンジ */
}
```

### 類似色

カラーホイールで隣接（30度離れている）：

```css
:root {
  --color1: hsl(200, 70%, 50%);  /* 青 */
  --color2: hsl(230, 70%, 50%);  /* 青紫 */
  --color3: hsl(170, 70%, 50%);  /* シアン */
}
```

### 明度のバリエーション

シェードとティントを作成：

```css
:root {
  --primary-100: hsl(200, 70%, 90%);  /* 最も明るい */
  --primary-300: hsl(200, 70%, 70%);
  --primary-500: hsl(200, 70%, 50%);  /* ベース */
  --primary-700: hsl(200, 70%, 30%);
  --primary-900: hsl(200, 70%, 10%);  /* 最も暗い */
}
```

## FAQ

### 異なる画面で色が違って見えるのはなぜ？

画面によってカラープロファイル、明るさ、キャリブレーションが異なります。一貫した色のために：
- カラープロファイルを使用（Webにはsrgb）
- モニターをキャリブレーション
- 複数のデバイスでテスト

### HEXとRGBはいつ使うべき？

静的なCSS値にはHEX（よりクリーンなコード）を使用。以下が必要な場合はRGB/RGBAを使用：
- 透明度（RGBA）
- プログラム的な色操作
- 動的な色生成

### 色を明るくまたは暗くするには？

HSLでは、L（明度）の値を調整：
- 明るく：Lを増加（例：50% → 70%）
- 暗く：Lを減少（例：50% → 30%）

### HSLとHSVの違いは？

両方とも色相と彩度を使用しますが：
- HSL：明度（0% = 黒、100% = 白、50% = 純色）
- HSV：値/明るさ（0% = 黒、100% = 純色）

HSLはティントとシェードの作成により直感的です。
