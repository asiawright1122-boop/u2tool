# パスワードセキュリティのベストプラクティス：2025年完全ガイド

パスワードセキュリティは、サイバーセキュリティの最も重要な側面の1つです。この包括的なガイドでは、強力なパスワードの作成方法、一般的な攻撃、ユーザーと開発者のためのベストプラクティスを解説します。

## パスワードセキュリティが重要な理由

最近のサイバーセキュリティレポートによると：

- データ侵害の**81%**は弱いまたは盗まれたパスワードに関係
- **65%**の人が複数のアカウントでパスワードを再利用
- **2300万**のアカウントがまだ「123456」をパスワードとして使用
- データ侵害の平均コスト：**445万ドル**

## 強力なパスワードとは？

### パスワード強度の要因

| 要因 | 弱い | 強い |
|------|------|------|
| 長さ | 6-8文字 | 12文字以上 |
| 文字種 | 文字のみ | 混合（大文字、小文字、数字、記号） |
| 予測可能性 | 辞書の単語 | ランダムな組み合わせ |
| 一意性 | 再利用 | アカウントごとに一意 |

### 解読にかかる時間（2025年推定）

| パスワードタイプ | 例 | 解読時間 |
|------------------|-----|----------|
| 6文字小文字 | `abcdef` | 即座 |
| 8文字小文字 | `password` | 5秒 |
| 8文字大小混合 | `PassWord` | 22分 |
| 8文字混合+数字 | `Pass1234` | 1時間 |
| 12文字混合+記号 | `P@ss1234!abc` | 34,000年 |
| 16文字ランダム | `kX9#mP2$vL5@nQ8&` | 数世紀 |


## 一般的なパスワード攻撃

### 1. ブルートフォース攻撃

すべての可能な組み合わせを試行：

```
a, b, c, ... aa, ab, ac, ... aaa, aab, ...
```

**防御**：混合文字を含む長いパスワード

### 2. 辞書攻撃

一般的な単語とパスワードを使用：

```
password, 123456, qwerty, admin, letmein...
```

**防御**：辞書の単語を避ける

### 3. クレデンシャルスタッフィング

他の侵害から漏洩した認証情報を使用：

```
email: user@example.com
password: サイトAから漏洩したパスワード
```

**防御**：各アカウントに一意のパスワード

### 4. フィッシング

ユーザーを騙してパスワードを明かさせる：

```
偽のログインページ -> 認証情報をキャプチャ
```

**防御**：URLを確認、2FAを使用

## ユーザーのためのベストプラクティス

### すべきこと ✅

1. すべてのアカウントに**一意のパスワード**を使用
2. **パスワードマネージャー**を使用（1Password、Bitwardenなど）
3. 可能な限り**2FA/MFA**を有効化
4. 最低**12文字以上**を使用
5. **すべての文字種**を含める（大文字、小文字、数字、記号）
6. 侵害後は**パスワードを変更**
7. 利用可能な場合は**パスキー**を使用（パスワードレス）

### すべきでないこと ❌

1. アカウント間でパスワードを**再利用しない**
2. **個人情報**を使用しない（誕生日、名前、ペット）
3. **一般的なパターン**を使用しない（Password1!、Qwerty123）
4. メールやテキストでパスワードを**共有しない**
5. 付箋にパスワードを**書かない**
6. 本当の答えで**セキュリティの質問**を使用しない
7. 侵害通知を**無視しない**

## FAQ

### パスワードはどのくらいの頻度で変更すべき？

現在のガイダンス（NIST 2024）：スケジュールでパスワードを変更しない。以下の場合のみ変更：
- 侵害の疑いがある
- サービスが侵害を報告
- パスワードを共有した
- 弱いパスワードを使用した

頻繁な強制変更は、より弱いパスワードにつながります。

### 長いパスワードは常に良い？

一般的にはい、しかし品質も重要です。「aaaaaaaaaaaa」（12文字）は「Tr0ub4dor&3」（11文字）より弱いです。長さと複雑さの両方を目指してください。

### パスフレーズはランダムパスワードより安全？

「correct-horse-battery-staple」のような4単語のパスフレーズは約44ビットのエントロピーを持ちます。12文字のランダムパスワードは約79ビットです。ランダムパスワードの方が強力ですが、パスフレーズは覚えやすいです。

### 特殊文字を使用すべき？

はい、ただし末尾に「!」を追加するだけではありません。パスワード全体に特殊文字を分散させてください。「P@ss!w0rd#2025」は「Password2025!」より良いです。

### 複雑なパスワードを覚えられない場合は？

パスワードマネージャーを使用してください。1つの強力なマスターパスワードを覚えるだけで済みます。マネージャーが他のすべてを処理します。
