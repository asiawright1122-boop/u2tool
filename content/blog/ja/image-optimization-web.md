# Web画像最適化：高速読み込みのための完全ガイド

画像最適化はWebパフォーマンスにとって非常に重要です。大きく最適化されていない画像は、Webサイトの読み込み速度を遅くする主な原因の1つです。このガイドでは、Web用画像最適化について知っておくべきすべてを解説します。

## 画像最適化が重要な理由

- **ページ速度**: 画像はWebページの総サイズの50-80%を占めることが多い
- **SEOランキング**: Googleはページ速度をランキング要因として使用
- **ユーザー体験**: 高速なサイトは直帰率が低い
- **帯域幅コスト**: 小さい画像はホスティングコストを削減
- **モバイルユーザー**: 最適化された画像はモバイルブラウジングに不可欠

## 画像フォーマットの説明

### JPEG (JPG)

写真や多くの色を持つ複雑な画像に最適です。

- **長所**: 小さいファイルサイズ、幅広いサポート
- **短所**: 非可逆圧縮、透明度なし
- **用途**: 写真、複雑なグラフィック

### PNG

透明度やシャープなエッジが必要な画像に最適です。

- **長所**: 可逆圧縮、透明度サポート
- **短所**: より大きいファイルサイズ
- **用途**: ロゴ、アイコン、スクリーンショット

### WebP

優れた圧縮を提供する現代的なフォーマットです。

- **長所**: JPEG/PNGより25-35%小さい、透明度サポート
- **短所**: 古いブラウザでサポートされない
- **用途**: すべてのWeb画像（フォールバック付き）


### SVG

スケーラブルなグラフィック用のベクターフォーマットです。

- **長所**: 無限にスケーラブル、シンプルなグラフィックの場合は小さいファイルサイズ
- **短所**: 写真には適さない
- **用途**: アイコン、ロゴ、イラスト

### AVIF

優れた圧縮を提供する次世代フォーマットです。

- **長所**: JPEGより50%小さい、高品質
- **短所**: 限られたブラウザサポート
- **用途**: 画像の将来対応

## 最適化テクニック

### 1. 適切なフォーマットを選択

| 画像タイプ | 推奨フォーマット |
|------------|------------------|
| 写真 | WebP（JPEGフォールバック） |
| アイコン/ロゴ | SVGまたはPNG |
| スクリーンショット | PNGまたはWebP |
| アニメーション | WebPまたはGIF |

### 2. 画像のリサイズ

必要以上に大きい画像をアップロードしないでください。

### 3. 画像の圧縮

圧縮ツールを使用してファイルサイズを削減：

- **非可逆圧縮**: 一部のデータを削除（JPEG品質80-85%）
- **可逆圧縮**: 品質を損なわずにメタデータを削除

### 4. 遅延読み込み

ビューポートに入ったときにのみ画像を読み込みます：

```html
<img src="image.jpg" loading="lazy" alt="説明">
```

## パフォーマンス指標

### 目標ファイルサイズ

| 画像タイプ | 目標サイズ |
|------------|------------|
| ヒーロー画像 | < 200KB |
| コンテンツ画像 | < 100KB |
| サムネイル | < 30KB |
| アイコン | < 5KB |
