# Leitfaden zur Farbformat-Konvertierung: HEX, RGB, HSL und mehr

Das Verständnis von Farbformaten ist für Webentwickler und Designer unerlässlich. Dieser umfassende Leitfaden erklärt verschiedene Farbmodelle, wann jedes verwendet werden sollte und wie man zwischen ihnen konvertiert.

## Übersicht der Farbmodelle

### RGB (Rot, Grün, Blau)

Das häufigste digitale Farbmodell, basierend auf additiver Farbmischung:

```
Format: rgb(red, green, blue)
Bereich: 0-255 für jeden Kanal
Beispiel: rgb(255, 99, 71) - Tomatenrot
```

### HEX (Hexadezimal)

Kompakte Darstellung von RGB:

```
Format: #RRGGBB oder #RGB (Kurzform)
Bereich: 00-FF (0-255 in Hex)
Beispiel: #FF6347 - Tomatenrot
```

### HSL (Farbton, Sättigung, Helligkeit)

Intuitiver für Menschen:

```
Format: hsl(hue, saturation%, lightness%)
Farbton: 0-360 (Grad auf dem Farbkreis)
Sättigung: 0-100% (grau bis lebhaft)
Helligkeit: 0-100% (schwarz bis weiß)
```

## Wann welches Format verwenden

| Format | Am besten für | Vorteile | Nachteile |
|--------|---------------|----------|-----------|
| HEX | CSS, Webdesign | Kompakt, breite Unterstützung | Schwer zu lesen/ändern |
| RGB | Programmatische Manipulation | Einfache mathematische Operationen | Nicht intuitiv |
| HSL | Farbschemata erstellen | Intuitive Anpassungen | Weniger verbreitet |
