## Questions Fréquentes (FAQ)

### Qu'est-ce que le formatage JSON ?

Le formatage JSON (aussi appelé embellissement ou pretty-printing) ajoute une indentation et des sauts de ligne appropriés au JSON minifié, le rendant lisible par l'homme. Il ne change pas les données, seulement la présentation visuelle.

### Est-il sûr d'utiliser des formateurs JSON en ligne ?

Cela dépend de l'outil. Certains formateurs téléchargent vos données sur des serveurs, ce qui pose des risques de sécurité. Des outils comme U2Tool JSON Formatter fonctionnent entièrement dans votre navigateur, donc vos données ne quittent jamais votre appareil.

### Quelle est la différence entre validation et formatage JSON ?

La validation vérifie si la syntaxe JSON est correcte et signale les erreurs. Le formatage rend le JSON valide lisible en ajoutant une indentation. La plupart des outils font les deux - ils valident d'abord, puis formatent si valide.

### Les formateurs JSON peuvent-ils gérer de gros fichiers ?

Les formateurs basés sur navigateur peuvent généralement gérer des fichiers de plusieurs mégaoctets. Pour de très gros fichiers (100Mo+), envisagez d'utiliser des outils en ligne de commande comme jq ou des applications de bureau.

### Pourquoi mon JSON est-il invalide ?

Les erreurs JSON courantes incluent :
- Virgules manquantes ou en trop
- Clés non entre guillemets (les clés doivent être entre guillemets doubles)
- Guillemets simples au lieu de guillemets doubles
- Virgules finales après le dernier élément
- Commentaires (JSON ne supporte pas les commentaires)
