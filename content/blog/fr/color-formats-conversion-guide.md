# Guide de Conversion des Formats de Couleur : HEX, RGB, HSL et Plus

Comprendre les formats de couleur est essentiel pour les développeurs web et les designers. Ce guide complet explique les différents modèles de couleur, quand utiliser chacun et comment convertir entre eux.

## Aperçu des Modèles de Couleur

### RGB (Rouge, Vert, Bleu)

Le modèle de couleur numérique le plus courant, basé sur le mélange additif :

```
Format : rgb(red, green, blue)
Plage : 0-255 pour chaque canal
Exemple : rgb(255, 99, 71) - Rouge tomate
```

### HEX (Hexadécimal)

Représentation compacte de RGB :

```
Format : #RRGGBB ou #RGB (abrégé)
Plage : 00-FF (0-255 en hex)
Exemple : #FF6347 - Rouge tomate
```

### HSL (Teinte, Saturation, Luminosité)

Plus intuitif pour les humains :

```
Format : hsl(hue, saturation%, lightness%)
Teinte : 0-360 (degrés sur la roue des couleurs)
Saturation : 0-100% (gris à vif)
Luminosité : 0-100% (noir à blanc)
```

## Quand Utiliser Chaque Format

| Format | Meilleur Pour | Avantages | Inconvénients |
|--------|---------------|-----------|---------------|
| HEX | CSS, design web | Compact, large support | Difficile à lire/modifier |
| RGB | Manipulation programmatique | Opérations mathématiques faciles | Pas intuitif |
| HSL | Créer des schémas de couleurs | Ajustements intuitifs | Moins courant |
