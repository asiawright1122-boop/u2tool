# 二维码完整指南：生成、最佳实践和应用场景

二维码已经在我们的数字世界中无处不在。本指南涵盖从二维码基础到高级生成技术和实际应用的所有内容。

## 什么是二维码？

二维码（QR Code，Quick Response Code）是由 Denso Wave 于 1994 年发明的二维条形码。与传统条形码水平存储数据不同，二维码同时在水平和垂直方向存储数据，允许存储更多信息。

### 二维码容量

| 数据类型 | 最大容量 |
|----------|----------|
| 数字 | 7,089 字符 |
| 字母数字 | 4,296 字符 |
| 二进制/字节 | 2,953 字节 |
| 汉字 | 1,817 字符 |

## 二维码版本

二维码有 40 个版本（1-40），每个版本有不同的大小：

| 版本 | 模块数 | 数据容量（L 级） |
|------|--------|------------------|
| 1 | 21×21 | 25 字母数字 |
| 10 | 57×57 | 174 字母数字 |
| 20 | 97×97 | 858 字母数字 |
| 40 | 177×177 | 4,296 字母数字 |

版本越高 = 数据越多但二维码越大。

## 纠错级别

二维码即使部分损坏也能被读取：

| 级别 | 恢复能力 | 使用场景 |
|------|----------|----------|
| L（低） | ~7% | 干净环境，最大数据量 |
| M（中） | ~15% | 一般用途，平衡 |
| Q（四分之一） | ~25% | 户外，预期中等损坏 |
| H（高） | ~30% | 恶劣条件，中心有 Logo |

**建议**：大多数情况使用 M 级，添加 Logo 时使用 H 级。

## 二维码数据类型

### 1. URL

最常见的用途：

```
https://www.u2tool.com/zh/tools/qr-generator
```

### 2. 纯文本

简单文本消息：

```
你好，这是一条二维码消息！
```

### 3. 电子邮件

预填充邮件：

```
mailto:contact@example.com?subject=你好&body=消息内容
```

### 4. 电话号码

点击拨打：

```
tel:+8613812345678
```

### 5. 短信

预填充短信：

```
smsto:+8613812345678:您的消息内容
```

### 6. WiFi 凭据

自动连接 WiFi：

```
WIFI:T:WPA;S:网络名称;P:密码;;
```

格式说明：
- `T:` - 安全类型（WPA、WEP、nopass）
- `S:` - 网络名称（SSID）
- `P:` - 密码
- `H:true` - 隐藏网络（可选）

### 7. vCard（联系人）

分享联系信息：

```
BEGIN:VCARD
VERSION:3.0
N:张;三
FN:张三
TEL:+8613812345678
EMAIL:zhangsan@example.com
END:VCARD
```

### 8. 日历事件

添加事件到日历：

```
BEGIN:VEVENT
SUMMARY:会议
DTSTART:20250115T100000
DTEND:20250115T110000
LOCATION:会议室
END:VEVENT
```

### 9. 地理位置

在地图上打开位置：

```
geo:39.9042,116.4074
```

### 10. 支付

```
支付宝/微信支付二维码
```

## 二维码设计最佳实践

### 尺寸指南

| 使用场景 | 最小尺寸 | 推荐尺寸 |
|----------|----------|----------|
| 名片 | 2cm × 2cm | 2.5cm × 2.5cm |
| 传单/海报 | 3cm × 3cm | 4cm × 4cm |
| 广告牌 | 10cm × 10cm | 15cm × 15cm |

**经验法则**：二维码应至少是扫描距离的 1/10。

### 静区

始终在二维码周围保持空白：

```
┌─────────────────────┐
│                     │  ← 静区（至少 4 个模块）
│   ┌─────────────┐   │
│   │  二维码     │   │
│   │             │   │
│   └─────────────┘   │
│                     │
└─────────────────────┘
```

### 颜色对比

- **最小对比度**：4:1
- **深色前景，浅色背景**（不要反转）
- 避免：红/绿组合（色盲）
- 测试：用多个设备扫描

### 添加 Logo

在中心添加 Logo 时：

1. 使用 **H 级**纠错
2. Logo 保持在二维码面积的 **30% 以下**
3. 保持 Logo 周围的**对比度**
4. 添加 Logo 后**测试扫描**


## 动态 vs 静态二维码

### 静态二维码

- 数据直接编码在二维码中
- 创建后无法更改
- 免费创建
- 最适合：永久信息

### 动态二维码

- 二维码链接到重定向 URL
- 内容可随时更改
- 通常需要订阅
- 最适合：营销活动、追踪

| 特性 | 静态 | 动态 |
|------|------|------|
| 可编辑 | ❌ | ✅ |
| 追踪 | ❌ | ✅ |
| 成本 | 免费 | 付费 |
| 大小 | 较大（更多数据） | 较小（短 URL） |

## 二维码安全

### 潜在风险

1. **恶意 URL**：二维码可能链接到钓鱼网站
2. **恶意软件下载**：自动下载有害文件
3. **数据盗窃**：假支付二维码
4. **二维码替换**：物理篡改

### 用户安全提示

- 打开前**预览 URL**
- 使用**可信扫描器**，先显示 URL
- **验证来源**
- **不要扫描**可疑或损坏的二维码
- **检查篡改**（原始上的贴纸）

### 创建者安全提示

- 使用 **HTTPS** URL
- 实现带预览的 **URL 短链接**
- 添加**品牌元素**防止替换
- **监控**未授权副本
- 敏感内容使用**动态二维码**

## 常见问题

### 下载二维码的最佳格式是什么？

- **PNG**：最适合网页、社交媒体、数字用途
- **SVG**：最适合印刷，无损缩放
- **PDF**：适合专业印刷

### 二维码可以多小？

最小推荐：2cm × 2cm（0.8 英寸）。更小的二维码可能无法可靠扫描，特别是有 Logo 或复杂数据时。

### 二维码会过期吗？

静态二维码永不过期。动态二维码如果服务停止或订阅失效可能会过期。

### 为什么我的二维码无法扫描？

常见问题：
- 对于扫描距离来说太小
- 对比度差（浅色配浅色）
- 表面损坏或脏污
- 数据太多（复杂二维码）
- 缺少静区
- Logo 太大

### 我可以追踪二维码扫描吗？

静态二维码：没有内置追踪。使用带分析的 URL 短链接。
动态二维码：是的，大多数服务提供扫描分析。

### 二维码免费使用吗？

创建和使用二维码是免费的。该技术是开放的，没有专利（专利于 2015 年到期）。一些服务对动态二维码或高级功能收费。

### 二维码和条形码有什么区别？

| 特性 | 二维码 | 条形码 |
|------|--------|--------|
| 维度 | 2D | 1D |
| 数据容量 | ~4,000 字符 | ~20 字符 |
| 纠错 | 有 | 无 |
| 扫描角度 | 任意 | 仅水平 |
