# 网页图片优化：加速网站加载完整指南

图片优化对网页性能至关重要。未优化的大图片是导致网站加载缓慢的主要原因之一。本指南涵盖了网页图片优化的所有知识。

## 为什么图片优化很重要

- **页面速度**：图片通常占网页总大小的 50-80%
- **SEO 排名**：Google 将页面速度作为排名因素
- **用户体验**：更快的网站跳出率更低
- **带宽成本**：更小的图片降低托管成本
- **移动用户**：优化图片对移动浏览至关重要

## 图片格式详解

### JPEG (JPG)

最适合照片和颜色丰富的复杂图像。

- **优点**：文件小，支持广泛
- **缺点**：有损压缩，不支持透明
- **适用于**：照片、复杂图形

### PNG

最适合需要透明度或锐利边缘的图像。

- **优点**：无损压缩，支持透明
- **缺点**：文件较大
- **适用于**：Logo、图标、截图

### WebP

提供卓越压缩的现代格式。

- **优点**：比 JPEG/PNG 小 25-35%，支持透明
- **缺点**：旧浏览器不支持
- **适用于**：所有网页图片（需要回退方案）

### SVG

可缩放图形的矢量格式。

- **优点**：无限缩放，简单图形文件极小
- **缺点**：不适合照片
- **适用于**：图标、Logo、插图

### AVIF

具有出色压缩的下一代格式。

- **优点**：比 JPEG 小 50%，高质量
- **缺点**：浏览器支持有限
- **适用于**：面向未来的图片

## 优化技术

### 1. 选择正确的格式

| 图片类型 | 推荐格式 |
|----------|----------|
| 照片 | WebP（JPEG 回退）|
| 图标/Logo | SVG 或 PNG |
| 截图 | PNG 或 WebP |
| 动画 | WebP 或 GIF |

### 2. 调整图片尺寸

永远不要上传比需要更大的图片：

```html
<!-- 错误：4000x3000 的图片显示为 800x600 -->
<img src="huge-image.jpg" width="800" height="600">

<!-- 正确：图片尺寸与显示尺寸一致 -->
<img src="optimized-image.jpg" width="800" height="600">
```

### 3. 压缩图片

使用压缩工具减小文件大小：

- **有损压缩**：移除部分数据（JPEG 质量 80-85%）
- **无损压缩**：移除元数据但不损失质量

### 4. 懒加载

仅在图片进入视口时加载：

```html
<img src="image.jpg" loading="lazy" alt="描述">
```

### 5. 响应式图片

为不同设备提供不同尺寸：

```html
<img 
  srcset="small.jpg 480w, medium.jpg 800w, large.jpg 1200w"
  sizes="(max-width: 600px) 480px, (max-width: 1000px) 800px, 1200px"
  src="medium.jpg"
  alt="响应式图片"
>
```

## 图片优化工具

### 在线工具

1. **TinyPNG/TinyJPG** - 简单的拖放压缩
2. **Squoosh** - Google 的高级图片优化器
3. **ImageOptim** - Mac 批量优化应用
4. **SVGOMG** - SVG 优化工具

### 命令行工具

```bash
# ImageMagick - 调整大小和转换
convert input.jpg -resize 800x600 -quality 85 output.jpg

# cwebp - 转换为 WebP
cwebp -q 80 input.jpg -o output.webp

# svgo - 优化 SVG
svgo input.svg -o output.svg
```
