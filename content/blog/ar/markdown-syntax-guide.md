# دليل صياغة Markdown: مرجع شامل للمطورين

Markdown هي لغة ترميز خفيفة تتيح لك كتابة محتوى منسق باستخدام نص عادي. يغطي هذا الدليل الشامل جميع صياغات Markdown من الأساسية إلى المتقدمة.

## ما هو Markdown؟

تم إنشاء Markdown بواسطة John Gruber في عام 2004 كطريقة لكتابة محتوى سهل القراءة بتنسيق نص عادي مع إمكانية تحويله إلى HTML. يُستخدم الآن على نطاق واسع للتوثيق وملفات README ومنشورات المدونات والمزيد.

## الصياغة الأساسية

### العناوين

استخدم رموز الهاش (#) لإنشاء العناوين:

```markdown
# عنوان 1
## عنوان 2
### عنوان 3
#### عنوان 4
##### عنوان 5
###### عنوان 6
```

### تنسيق النص

- **غامق**: `**نص غامق**` أو `__نص غامق__`
- *مائل*: `*نص مائل*` أو `_نص مائل_`
- ***غامق ومائل***: `***غامق ومائل***`
- ~~يتوسطه خط~~: `~~يتوسطه خط~~`
- `كود`: `` `كود مضمن` ``


### القوائم

**القوائم غير المرتبة:**
```markdown
- عنصر 1
- عنصر 2
  - عنصر متداخل
  - عنصر متداخل آخر
- عنصر 3
```

**القوائم المرتبة:**
```markdown
1. العنصر الأول
2. العنصر الثاني
3. العنصر الثالث
```

### الروابط والصور

**الروابط:**
```markdown
[نص الرابط](https://example.com)
[رابط مع عنوان](https://example.com "العنوان")
```

**الصور:**
```markdown
![نص بديل](image-url.jpg)
![نص بديل](image-url.jpg "عنوان الصورة")
```

## الصياغة المتقدمة

### كتل الكود

استخدم ثلاث علامات اقتباس خلفية لكتل الكود مع تمييز الصياغة:

```javascript
function greet(name) {
  return `مرحباً، ${name}!`;
}
```

### الجداول

```markdown
| العمود 1 | العمود 2 | العمود 3 |
|----------|----------|----------|
| خلية 1   | خلية 2   | خلية 3   |
| خلية 4   | خلية 5   | خلية 6   |
```

### الاقتباسات

```markdown
> هذا اقتباس.
> يمكن أن يمتد على عدة أسطر.
>
> > الاقتباسات المتداخلة ممكنة أيضاً.
```

### قوائم المهام

```markdown
- [x] مهمة مكتملة
- [ ] مهمة غير مكتملة
- [ ] مهمة أخرى
```

### الخطوط الأفقية

استخدم ثلاثة شرطات أو نجوم أو شرطات سفلية أو أكثر:

```markdown
---
***
___
```


## ميزات Markdown الموسعة

### الحواشي السفلية

```markdown
هذه جملة مع حاشية سفلية.[^1]

[^1]: هذا محتوى الحاشية السفلية.
```

### قوائم التعريفات

```markdown
المصطلح
: تعريف المصطلح
```

### الاختصارات

```markdown
يتم صيانة مواصفات HTML بواسطة W3C.

*[HTML]: Hyper Text Markup Language
*[W3C]: World Wide Web Consortium
```

## أفضل الممارسات

1. **استخدم تنسيقاً متسقاً** - حافظ على نمط واحد في جميع أنحاء المستند
2. **أضف أسطراً فارغة** - افصل العناصر المختلفة بأسطر فارغة لتحسين القراءة
3. **استخدم روابط نمط المرجع** - للمستندات التي تحتوي على روابط كثيرة
4. **معاينة عملك** - قم دائماً بمعاينة Markdown قبل النشر
5. **حافظ على البساطة** - لا تعقد الأمور؛ Markdown مصمم ليكون قابلاً للقراءة

## حالات الاستخدام الشائعة

- **ملفات README** - توثيق المشاريع على GitHub
- **التوثيق** - التوثيق التقني والويكي
- **منشورات المدونة** - أنظمة إدارة المحتوى
- **الملاحظات** - تطبيقات تدوين الملاحظات الشخصية
- **التعليقات** - المنتديات ومنصات النقاش

## الخلاصة

Markdown مهارة أساسية للمطورين ومنشئي المحتوى. بساطته وسهولة قراءته تجعله الخيار المفضل للتوثيق التقني. تدرب على عناصر الصياغة هذه وستكتب Markdown بطلاقة في وقت قصير.
