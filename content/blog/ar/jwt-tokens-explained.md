# شرح رموز JWT: دليل شامل لـ JSON Web Tokens

رموز JSON Web Tokens (JWT) هي المعيار الصناعي للمصادقة الآمنة وتبادل المعلومات. يغطي هذا الدليل بنية JWT وكيفية عملها وأفضل ممارسات الأمان ونصائح التنفيذ.

## ما هو JWT؟

JWT (JSON Web Token) هو معيار مفتوح (RFC 7519) لنقل المعلومات بشكل آمن بين الأطراف ككائن JSON. رموز JWT هي:

- **مضغوطة**: حجم صغير، مناسبة لـ URLs وترويسات HTTP
- **مكتفية ذاتياً**: تحتوي على جميع معلومات المستخدم الضرورية
- **قابلة للتحقق**: موقعة رقمياً لضمان السلامة

## بنية JWT

يتكون JWT من ثلاثة أجزاء مفصولة بنقاط:

```
xxxxx.yyyyy.zzzzz
Header.Payload.Signature
```

### 1. Header

يحتوي على نوع الرمز وخوارزمية التوقيع:

```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

### 2. Payload

يحتوي على المطالبات (بيانات عن المستخدم):

```json
{
  "sub": "1234567890",
  "name": "محمد أحمد",
  "email": "mohamed@example.com",
  "iat": 1516239022,
  "exp": 1516242622
}
```

## أفضل ممارسات الأمان

### 1. استخدام أسرار قوية

لـ HS256، استخدم أسرار عشوائية 256 بت على الأقل.

### 2. تعيين انتهاء صلاحية مناسب

الرموز قصيرة العمر تقلل المخاطر.

### 3. استخدام HTTPS فقط

دائماً أرسل JWT عبر HTTPS لمنع الاعتراض.
