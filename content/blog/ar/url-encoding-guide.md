# دليل ترميز URL: كل ما تحتاج معرفته

ترميز URL (يُسمى أيضاً الترميز النسبي) ضروري لتطوير الويب. يشرح هذا الدليل لماذا تحتاج URLs للترميز، كيف يعمل، والأخطاء الشائعة التي يجب تجنبها.

## لماذا يوجد ترميز URL

URLs يمكنها فقط احتواء مجموعة محدودة من الأحرف من مجموعة ASCII. عندما تحتاج لتضمين أحرف خاصة أو مسافات أو أحرف غير ASCII في URL، يجب ترميزها.

### الأحرف المحجوزة

هذه الأحرف لها معنى خاص في URLs:

| الحرف | الغرض | مُرمَّز |
|-------|-------|--------|
| : | فاصل البروتوكول | %3A |
| / | فاصل المسار | %2F |
| ? | بداية سلسلة الاستعلام | %3F |
| # | معرف الجزء | %23 |
| & | فاصل المعاملات | %26 |

## كيف يعمل ترميز URL

ترميز URL يحول الأحرف إلى قيمها ASCII السداسية عشرية مسبوقة بعلامة النسبة المئوية:

```
الحرف → كود ASCII → قيمة Hex → %قيمةHex

مسافة → 32 → 20 → %20
! → 33 → 21 → %21
@ → 64 → 40 → %40
```

## دوال الترميز في JavaScript

| الدالة | حالة الاستخدام |
|--------|---------------|
| `encodeURI` | ترميز URL كامل |
| `encodeURIComponent` | ترميز معاملات URL |
| `URLSearchParams` | بناء سلاسل الاستعلام |

## أفضل الممارسات

1. **دائماً رمّز إدخال المستخدم** قبل تضمينه في URLs
2. **استخدم `encodeURIComponent`** لمعاملات الاستعلام
3. **فضّل `URLSearchParams`** لبناء سلاسل الاستعلام

## الخلاصة

ترميز URL مفهوم ويب أساسي يجب على كل مطور فهمه.
