# دليل تحويل تنسيقات الألوان: HEX و RGB و HSL والمزيد

فهم تنسيقات الألوان ضروري لمطوري الويب والمصممين. يشرح هذا الدليل الشامل نماذج الألوان المختلفة ومتى تستخدم كل منها وكيفية التحويل بينها.

## نظرة عامة على نماذج الألوان

### RGB (أحمر، أخضر، أزرق)

نموذج الألوان الرقمي الأكثر شيوعاً، يعتمد على المزج الإضافي:

```
التنسيق: rgb(red, green, blue)
النطاق: 0-255 لكل قناة
مثال: rgb(255, 99, 71) - أحمر طماطم
```

### HEX (سداسي عشري)

تمثيل مضغوط لـ RGB:

```
التنسيق: #RRGGBB أو #RGB (مختصر)
النطاق: 00-FF (0-255 بالسداسي عشري)
مثال: #FF6347 - أحمر طماطم
```

### HSL (درجة اللون، التشبع، الإضاءة)

أكثر بديهية للبشر:

```
التنسيق: hsl(hue, saturation%, lightness%)
درجة اللون: 0-360 (درجات على عجلة الألوان)
التشبع: 0-100% (رمادي إلى حيوي)
الإضاءة: 0-100% (أسود إلى أبيض)
```

## متى تستخدم كل تنسيق

| التنسيق | الأفضل لـ | المزايا | العيوب |
|---------|----------|---------|--------|
| HEX | CSS، تصميم الويب | مضغوط، دعم واسع | صعب القراءة/التعديل |
| RGB | التلاعب البرمجي | عمليات رياضية سهلة | غير بديهي |
| HSL | إنشاء مخططات الألوان | تعديلات بديهية | أقل شيوعاً |
