# دليل طابع Unix الزمني: العمل مع وقت Epoch

طوابع Unix الزمنية هي الطريقة العالمية لتمثيل الوقت في الحوسبة. يغطي هذا الدليل كل شيء من المفاهيم الأساسية إلى التطبيقات العملية ومشكلة عام 2038.

## ما هو طابع Unix الزمني؟

طابع Unix الزمني (يُسمى أيضاً وقت Epoch أو وقت POSIX) هو عدد الثواني التي مرت منذ 1 يناير 1970، 00:00:00 UTC. تُسمى هذه اللحظة "Unix Epoch".

```
Unix Epoch: 1 يناير 1970، 00:00:00 UTC
الطابع الزمني: 0

مثال على الوقت الحالي:
13 يناير 2025، 12:00:00 UTC
الطابع الزمني: 1736769600
```

## لماذا نستخدم طوابع Unix الزمنية؟

1. **عالمية**: نفس القيمة بغض النظر عن المنطقة الزمنية
2. **بسيطة**: مجرد رقم، سهل التخزين والمقارنة
3. **مضغوطة**: تأخذ مساحة أقل من سلاسل التاريخ
4. **قابلة للفرز**: المقارنة الرقمية تعمل بشكل طبيعي
5. **مستقلة عن اللغة**: تعمل في أي لغة برمجة

## تحويل الطوابع الزمنية

### JavaScript

```javascript
// الطابع الزمني الحالي (ثواني)
const timestamp = Math.floor(Date.now() / 1000);

// الطابع الزمني إلى Date
const date = new Date(timestamp * 1000);

// Date إلى طابع زمني
const ts = Math.floor(new Date('2025-01-13').getTime() / 1000);
```

## مشكلة عام 2038

تخزن أنظمة 32 بت الطوابع الزمنية كأعداد صحيحة موقعة بقيمة قصوى 2,147,483,647. هذا يتوافق مع 19 يناير 2038، 03:14:07 UTC.

## الخلاصة

طوابع Unix الزمنية ضرورية لأي مطور يعمل مع التواريخ والأوقات. تذكر مراعاة المناطق الزمنية عند العرض للمستخدمين.
