# شرح ترميز Base64: دليل شامل مع أدوات عبر الإنترنت

Base64 هو نظام ترميز يمثل البيانات الثنائية باستخدام 64 حرفاً قابلاً للطباعة. يُستخدم على نطاق واسع في تطوير الويب ونقل البيانات ومرفقات البريد الإلكتروني والمزيد. يشرح هذا المقال كيفية عمل Base64 ويوصي بأدوات عملية عبر الإنترنت.

## ما هو ترميز Base64؟

يستخدم ترميز Base64 هذه الأحرف الـ 64 لتمثيل البيانات:
- الأحرف الكبيرة: A-Z (26)
- الأحرف الصغيرة: a-z (26)
- الأرقام: 0-9 (10)
- الأحرف الخاصة: + و / (2)

بالإضافة إلى ذلك، يُستخدم = كحرف حشو.

## كيف يعمل ترميز Base64

المبدأ الأساسي لـ Base64 هو تحويل 3 بايت (24 بت) من البيانات إلى 4 أحرف Base64 (6 بت لكل منها).

### خطوات الترميز

1. تحويل بيانات الإدخال إلى ثنائي
2. تقسيمها إلى مجموعات من 6 بت
3. تحويل كل مجموعة إلى حرف Base64 المقابل
4. الحشو بـ = إذا كانت المجموعة الأخيرة غير مكتملة

### مثال

ترميز "Hi" إلى Base64:

```
H = 01001000
i = 01101001

مجتمعة: 010010 000110 1001xx

بعد الحشو: 010010 000110 100100

تقابل: S      G      k      =

النتيجة: SGk=
```

## حالات الاستخدام الشائعة

### 1. الصور المضمنة

تضمين الصور مباشرة في HTML/CSS:

```html
<img src="data:image/png;base64,iVBORw0KGgo..." />
```

### 2. نقل بيانات API

نقل البيانات الثنائية في JSON:

```json
{
  "file": "SGVsbG8gV29ybGQh",
  "filename": "hello.txt"
}
```

### 3. مرفقات البريد الإلكتروني

يستخدم بروتوكول MIME ترميز Base64 لمرفقات البريد الإلكتروني.

### 4. رموز JWT

تستخدم رموز JSON Web ترميز Base64URL.

## مزايا وعيوب Base64

### المزايا
- نقل البيانات الثنائية في بروتوكولات النص
- البيانات المرمزة تحتوي فقط على أحرف قابلة للطباعة
- مدعوم على نطاق واسع في جميع لغات البرمجة

### العيوب
- البيانات المرمزة أكبر بنسبة ~33%
- ليس تشفيراً، لا تستخدمه للأمان

## الأسئلة الشائعة (FAQ)

### هل Base64 تشفير؟

لا، Base64 هو ترميز وليس تشفيراً. لا يوفر أي أمان - يمكن لأي شخص فك ترميز بيانات Base64. لا تستخدم Base64 أبداً لحماية المعلومات الحساسة. استخدم خوارزميات تشفير مناسبة مثل AES للأمان.

### لماذا يزيد Base64 حجم الملف؟

يحول Base64 كل 3 بايت إلى 4 أحرف، مما يؤدي إلى زيادة الحجم بنسبة ~33%. هذا لأنه يستخدم فقط 64 حرفاً قابلاً للطباعة لتمثيل 256 قيمة بايت ممكنة.

### ما هو Base64URL؟

Base64URL هو متغير آمن للروابط من Base64. يستبدل `+` بـ `-` و `/` بـ `_`، وغالباً يحذف الحشو `=`. يُستخدم بشكل شائع في رموز JWT ومعاملات الروابط.

### متى يجب استخدام Base64؟

استخدم Base64 عندما تحتاج إلى:
- تضمين الصور في HTML/CSS (data URIs)
- نقل البيانات الثنائية في واجهات JSON API
- تخزين البيانات الثنائية في أنظمة النص فقط
- ترميز مرفقات البريد الإلكتروني (MIME)

### هل يمكن لـ Base64 ترميز أي نوع ملف؟

نعم، يمكن لـ Base64 ترميز أي بيانات ثنائية، بما في ذلك الصور وملفات PDF والملفات التنفيذية وأي نوع ملف آخر. النتيجة المرمزة دائماً نص عادي.
