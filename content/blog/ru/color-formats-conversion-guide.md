# Руководство по конвертации цветовых форматов: HEX, RGB, HSL и другие

Понимание цветовых форматов необходимо для веб-разработчиков и дизайнеров. Это полное руководство объясняет различные цветовые модели, когда использовать каждую и как конвертировать между ними.

## Обзор цветовых моделей

### RGB (Красный, Зелёный, Синий)

Наиболее распространённая цифровая цветовая модель, основанная на аддитивном смешивании:

```
Формат: rgb(red, green, blue)
Диапазон: 0-255 для каждого канала
Пример: rgb(255, 99, 71) - Томатный красный
```

### HEX (Шестнадцатеричный)

Компактное представление RGB:

```
Формат: #RRGGBB или #RGB (сокращённый)
Диапазон: 00-FF (0-255 в hex)
Пример: #FF6347 - Томатный красный
```

### HSL (Оттенок, Насыщенность, Светлота)

Более интуитивный для людей:

```
Формат: hsl(hue, saturation%, lightness%)
Оттенок: 0-360 (градусы на цветовом круге)
Насыщенность: 0-100% (серый до яркого)
Светлота: 0-100% (чёрный до белого)
```

## Когда использовать каждый формат

| Формат | Лучше для | Преимущества | Недостатки |
|--------|-----------|--------------|------------|
| HEX | CSS, веб-дизайн | Компактный, широкая поддержка | Трудно читать/изменять |
| RGB | Программная манипуляция | Простые математические операции | Не интуитивный |
| HSL | Создание цветовых схем | Интуитивные настройки | Менее распространён |
