# Руководство по URL-кодированию: Всё, что нужно знать

URL-кодирование (также называемое процентным кодированием) необходимо для веб-разработки. Это руководство объясняет, почему URL нуждаются в кодировании, как это работает и распространённые ошибки, которых следует избегать.

## Почему существует URL-кодирование

URL могут содержать только ограниченный набор символов из набора ASCII. Когда нужно включить специальные символы, пробелы или не-ASCII символы в URL, они должны быть закодированы.

### Зарезервированные символы

Эти символы имеют специальное значение в URL:

| Символ | Назначение | Закодировано |
|--------|------------|--------------|
| : | Разделитель протокола | %3A |
| / | Разделитель пути | %2F |
| ? | Начало строки запроса | %3F |
| # | Идентификатор фрагмента | %23 |
| & | Разделитель параметров | %26 |

## Как работает URL-кодирование

URL-кодирование преобразует символы в их шестнадцатеричные ASCII-значения с предшествующим знаком процента:

```
Символ → ASCII-код → Hex-значение → %HexЗначение

Пробел → 32 → 20 → %20
! → 33 → 21 → %21
@ → 64 → 40 → %40
```

## Функции кодирования JavaScript

| Функция | Случай использования |
|---------|---------------------|
| `encodeURI` | Кодирование полного URL |
| `encodeURIComponent` | Кодирование параметров URL |
| `URLSearchParams` | Построение строк запроса |

## Лучшие практики

1. **Всегда кодируйте пользовательский ввод** перед включением в URL
2. **Используйте `encodeURIComponent`** для параметров запроса
3. **Предпочитайте `URLSearchParams`** для построения строк запроса

## Заключение

URL-кодирование — это фундаментальная веб-концепция, которую должен понимать каждый разработчик.
