# Руководство по Unix-временным меткам: Работа с Epoch-временем

Unix-временные метки — это универсальный способ представления времени в вычислениях. Это руководство охватывает всё от базовых концепций до практических применений и проблемы 2038 года.

## Что такое Unix-временная метка?

Unix-временная метка (также называемая Epoch-временем или POSIX-временем) — это количество секунд, прошедших с 1 января 1970 года, 00:00:00 UTC. Этот момент называется "Unix Epoch".

```
Unix Epoch: 1 января 1970, 00:00:00 UTC
Временная метка: 0

Пример текущего времени:
13 января 2025, 12:00:00 UTC
Временная метка: 1736769600
```

## Почему использовать Unix-временные метки?

1. **Универсальность**: Одинаковое значение независимо от часового пояса
2. **Простота**: Просто число, легко хранить и сравнивать
3. **Компактность**: Занимает меньше места, чем строки дат
4. **Сортируемость**: Числовое сравнение работает естественно
5. **Независимость от языка**: Работает в любом языке программирования

## Преобразование временных меток

### JavaScript

```javascript
// Текущая временная метка (секунды)
const timestamp = Math.floor(Date.now() / 1000);

// Временная метка в Date
const date = new Date(timestamp * 1000);

// Date во временную метку
const ts = Math.floor(new Date('2025-01-13').getTime() / 1000);
```

## Константы времени

| Единица | Секунды |
|---------|---------|
| Минута | 60 |
| Час | 3 600 |
| День | 86 400 |
| Неделя | 604 800 |

## Проблема 2038 года

32-битные системы хранят временные метки как знаковые целые числа с максимальным значением 2 147 483 647. Это соответствует 19 января 2038, 03:14:07 UTC.

## Заключение

Unix-временные метки необходимы для любого разработчика, работающего с датами и временем. Помните о часовых поясах при отображении пользователям.
