# JWT токены: Полное руководство по JSON Web Tokens

JSON Web Tokens (JWT) — это отраслевой стандарт для безопасной аутентификации и обмена информацией. Это руководство охватывает структуру JWT, как они работают, лучшие практики безопасности и советы по реализации.

## Что такое JWT?

JWT (JSON Web Token) — это открытый стандарт (RFC 7519) для безопасной передачи информации между сторонами в виде JSON-объекта. JWT являются:

- **Компактными**: Маленький размер, подходят для URL и HTTP-заголовков
- **Самодостаточными**: Содержат всю необходимую информацию о пользователе
- **Проверяемыми**: Цифровая подпись гарантирует целостность

## Структура JWT

JWT состоит из трёх частей, разделённых точками:

```
xxxxx.yyyyy.zzzzz
Header.Payload.Signature
```

### 1. Header

Содержит тип токена и алгоритм подписи:

```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

### 2. Payload

Содержит claims (утверждения о пользователе):

```json
{
  "sub": "1234567890",
  "name": "Иван Петров",
  "email": "ivan@example.com",
  "iat": 1516239022,
  "exp": 1516242622
}
```

## Лучшие практики безопасности

### 1. Использовать надёжные секреты

Для HS256 использовать как минимум 256-битные случайные секреты.

### 2. Устанавливать подходящее время истечения

Короткоживущие токены снижают риск.

### 3. Использовать только HTTPS

Всегда передавать JWT через HTTPS для предотвращения перехвата.
