## Что такое QR-код?

QR-код (Quick Response) — это двумерный штрих-код, изобретённый Denso Wave в 1994 году. В отличие от традиционных штрих-кодов, которые хранят данные горизонтально, QR-коды хранят данные как горизонтально, так и вертикально, что позволяет вместить гораздо больше информации.

### Ёмкость QR-кода

| Тип данных | Максимальная ёмкость |
|------------|---------------------|
| Числовой | 7 089 символов |
| Буквенно-цифровой | 4 296 символов |
| Двоичный/Байт | 2 953 байта |
| Кандзи | 1 817 символов |

## Уровни коррекции ошибок

QR-коды можно читать даже при частичном повреждении:

| Уровень | Восстановление | Применение |
|---------|----------------|------------|
| L (Низкий) | ~7% | Чистые условия, максимум данных |
| M (Средний) | ~15% | Общее использование, сбалансированный |
| Q (Квартиль) | ~25% | На улице, умеренные повреждения |
| H (Высокий) | ~30% | Суровые условия, логотипы в центре |

## Типы данных QR-кода

### 1. URL

Самый распространённый случай использования:

```
https://www.u2tool.com/ru/tools/qr-generator
```

### 2. Данные WiFi

Автоподключение к WiFi:

```
WIFI:T:WPA;S:ИмяСети;P:Пароль;;
```

### 3. vCard (Контакт)

Поделиться контактной информацией:

```
BEGIN:VCARD
VERSION:3.0
N:Петров;Иван
FN:Иван Петров
TEL:+7-999-123-45-67
EMAIL:ivan@example.com
END:VCARD
```
