# Mejores Prácticas de Seguridad de Contraseñas: Guía Completa 2025

La seguridad de contraseñas sigue siendo uno de los aspectos más críticos de la ciberseguridad. Esta guía completa cubre cómo crear contraseñas fuertes, ataques comunes y mejores prácticas para usuarios y desarrolladores.

## Por Qué Importa la Seguridad de Contraseñas

Según informes recientes de ciberseguridad:

- **81%** de las brechas de datos involucran contraseñas débiles o robadas
- **65%** de las personas reutilizan contraseñas en múltiples cuentas
- **23 millones** de cuentas aún usan "123456" como contraseña
- Costo promedio de una brecha de datos: **$4.45 millones**

## ¿Qué Hace una Contraseña Fuerte?

### Factores de Fortaleza

| Factor | Débil | Fuerte |
|--------|-------|--------|
| Longitud | 6-8 caracteres | 12+ caracteres |
| Tipos de caracteres | Solo letras | Mixto (mayúsculas, minúsculas, números, símbolos) |
| Predictibilidad | Palabras del diccionario | Combinaciones aleatorias |
| Unicidad | Reutilizada | Única por cuenta |

### Tiempo para Descifrar (estimaciones 2025)

| Tipo de Contraseña | Ejemplo | Tiempo |
|--------------------|---------|--------|
| 6 minúsculas | `abcdef` | Instantáneo |
| 8 minúsculas | `password` | 5 segundos |
| 8 mixtas | `PassWord` | 22 minutos |
| 12 mixtas + símbolos | `P@ss1234!abc` | 34,000 años |

## Ataques Comunes de Contraseñas

### 1. Ataque de Fuerza Bruta

Prueba todas las combinaciones posibles.

**Defensa**: Contraseñas largas con caracteres mixtos

### 2. Ataque de Diccionario

Usa palabras y contraseñas comunes.

**Defensa**: Evitar palabras del diccionario

### 3. Credential Stuffing

Usa credenciales filtradas de otras brechas.

**Defensa**: Contraseñas únicas para cada cuenta

## Mejores Prácticas para Usuarios

### Hacer ✅

1. Usar **contraseñas únicas** para cada cuenta
2. Usar un **gestor de contraseñas**
3. Habilitar **2FA/MFA** donde sea posible
4. Usar mínimo **12+ caracteres**
5. Incluir **todos los tipos de caracteres**

### No Hacer ❌

1. **No reutilizar** contraseñas entre cuentas
2. **No usar información personal** (cumpleaños, nombres)
3. **No usar patrones comunes** (Password1!, Qwerty123)
4. **No compartir** contraseñas por email o texto
