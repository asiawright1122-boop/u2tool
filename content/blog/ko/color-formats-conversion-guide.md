# 색상 형식 변환 가이드: HEX, RGB, HSL 등

색상 형식을 이해하는 것은 웹 개발자와 디자이너에게 필수적입니다. 이 종합 가이드에서는 다양한 색상 모델, 각각의 사용 시기, 변환 방법을 설명합니다.

## 색상 모델 개요

### RGB(빨강, 초록, 파랑)

가장 일반적인 디지털 색상 모델, 가산 혼합 기반:

```
형식: rgb(red, green, blue)
범위: 각 채널 0-255
예: rgb(255, 99, 71) - 토마토 레드
```

### HEX(16진수)

RGB의 컴팩트한 표현:

```
형식: #RRGGBB 또는 #RGB(축약형)
범위: 00-FF(16진수로 0-255)
예: #FF6347 - 토마토 레드
```

### HSL(색상, 채도, 명도)

인간에게 더 직관적:

```
형식: hsl(hue, saturation%, lightness%)
색상: 0-360(색상환 각도)
채도: 0-100%(회색에서 선명)
명도: 0-100%(검정에서 흰색)
예: hsl(9, 100%, 64%) - 토마토 레드
```

## 각 형식의 사용 시기

| 형식 | 최적 용도 | 장점 | 단점 |
|------|----------|------|------|
| HEX | CSS, 웹 디자인 | 컴팩트, 널리 지원 | 읽기 어려움 |
| RGB | 프로그래밍적 색상 조작 | 계산 쉬움 | 직관적이지 않음 |
| HSL | 색상 스킴 생성 | 직관적 조정 | 덜 일반적 |

## 색상 변환 공식

### RGB에서 HEX로

```javascript
function rgbToHex(r, g, b) {
  return '#' + [r, g, b]
    .map(x => x.toString(16).padStart(2, '0'))
    .join('');
}

rgbToHex(255, 99, 71); // "#ff6347"
```

## FAQ

### 다른 화면에서 색상이 다르게 보이는 이유는?

화면마다 색상 프로필, 밝기, 캘리브레이션이 다릅니다. 일관된 색상을 위해:
- 색상 프로필 사용(웹에는 sRGB)
- 모니터 캘리브레이션
- 여러 기기에서 테스트

### HEX와 RGB는 언제 사용해야 하나요?

정적 CSS 값에는 HEX(더 깔끔한 코드)를 사용. 다음이 필요한 경우 RGB/RGBA 사용:
- 투명도(RGBA)
- 프로그래밍적 색상 조작
- 동적 색상 생성
