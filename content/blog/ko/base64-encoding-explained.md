# Base64 인코딩 설명: 온라인 도구와 함께하는 완벽 가이드

Base64는 64개의 인쇄 가능한 문자를 사용하여 이진 데이터를 표현하는 인코딩 방식입니다. 웹 개발, 데이터 전송, 이메일 첨부 파일 등에서 널리 사용됩니다. 이 글에서는 Base64의 작동 방식을 설명하고 실용적인 온라인 도구를 추천합니다.

## Base64 인코딩이란?

Base64 인코딩은 다음 64개 문자를 사용하여 데이터를 표현합니다:
- 대문자: A-Z (26)
- 소문자: a-z (26)
- 숫자: 0-9 (10)
- 특수 문자: + 와 / (2)

또한 =는 패딩 문자로 사용됩니다.

## Base64 인코딩 작동 방식

Base64의 핵심 원리는 3바이트(24비트)의 데이터를 4개의 Base64 문자(각 6비트)로 변환하는 것입니다.

### 인코딩 단계

1. 입력 데이터를 이진수로 변환
2. 6비트 그룹으로 분할
3. 각 그룹을 해당 Base64 문자로 변환
4. 마지막 그룹이 불완전하면 =로 패딩

### 예시

"Hi"를 Base64로 인코딩:

```
H = 01001000
i = 01101001

결합: 010010 000110 1001xx

패딩 후: 010010 000110 100100

대응: S      G      k      =

결과: SGk=
```

## 일반적인 사용 사례

### 1. 인라인 이미지

HTML/CSS에 이미지를 직접 삽입:

```html
<img src="data:image/png;base64,iVBORw0KGgo..." />
```

### 2. API 데이터 전송

JSON에서 이진 데이터 전송:

```json
{
  "file": "SGVsbG8gV29ybGQh",
  "filename": "hello.txt"
}
```

### 3. 이메일 첨부 파일

MIME 프로토콜은 이메일 첨부 파일에 Base64를 사용합니다.

### 4. JWT 토큰

JSON Web Token은 Base64URL 인코딩을 사용합니다.

## Base64의 장단점

### 장점
- 텍스트 프로토콜에서 이진 데이터 전송
- 인코딩된 데이터는 인쇄 가능한 문자만 포함
- 모든 프로그래밍 언어에서 널리 지원

### 단점
- 인코딩된 데이터는 약 33% 더 큼
- 암호화가 아님, 보안용으로 사용하지 말 것

## 자주 묻는 질문 (FAQ)

### Base64는 암호화인가요?

아니요, Base64는 인코딩이지 암호화가 아닙니다. 보안을 제공하지 않습니다 - 누구나 Base64 데이터를 디코딩할 수 있습니다. 민감한 정보를 보호하기 위해 Base64를 사용하지 마세요. 보안을 위해서는 AES와 같은 적절한 암호화 알고리즘을 사용하세요.

### Base64가 파일 크기를 증가시키는 이유는?

Base64는 3바이트를 4문자로 변환하여 약 33%의 크기 증가를 초래합니다. 이는 256개의 가능한 바이트 값을 표현하기 위해 64개의 인쇄 가능한 문자만 사용하기 때문입니다.

### Base64URL이란 무엇인가요?

Base64URL은 Base64의 URL 안전 변형입니다. `+`를 `-`로, `/`를 `_`로 대체하고, 종종 패딩 `=`를 생략합니다. JWT 토큰과 URL 매개변수에서 일반적으로 사용됩니다.

### 언제 Base64를 사용해야 하나요?

다음이 필요할 때 Base64를 사용하세요:
- HTML/CSS에 이미지 삽입 (data URI)
- JSON API에서 이진 데이터 전송
- 텍스트 전용 시스템에 이진 데이터 저장
- 이메일 첨부 파일 인코딩 (MIME)

### Base64는 모든 파일 유형을 인코딩할 수 있나요?

네, Base64는 이미지, PDF, 실행 파일 및 기타 모든 파일 유형을 포함한 모든 이진 데이터를 인코딩할 수 있습니다. 인코딩된 결과는 항상 일반 텍스트입니다.
